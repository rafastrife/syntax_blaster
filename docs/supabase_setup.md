# Integração do Ranking (Leaderboard) com Supabase

Para ativar o placar global (Leaderboard) no Syntax Blaster, você precisará de um banco de dados **Supabase** gratuito. O jogo já está todo programado para isso. Abaixo estão as instruções passo a passo para você configurar e liberar o placar de recordes!

## Passo 1: Criar o Projeto Supabase

1. Acesse [supabase.com](https://supabase.com) e crie uma conta (pode usar o GitHub).
2. Clique em **New Project**, dê um nome para ele (ex: `Syntax Blaster Rank`) e escolha a região mais próxima do seu público.
3. Aguarde o projeto ser provisionado (isso leva uns 2 min).

## Passo 2: Criar a Tabela do Placar (Table)

Acesse o menu **SQL Editor** do projeto Supabase (ícone 📝 na barra lateral esquerdo) e cole a seguinte query no editor central. Depois clique em **RUN**.

```sql
-- Cria a tabela de placares
CREATE TABLE public.scores (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name TEXT NOT NULL CHECK (char_length(name) = 3),
    score INT NOT NULL,
    wave INT NOT NULL,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Habilita o "Row Level Security" mas com permissões públicas para leitura/inserção
ALTER TABLE public.scores ENABLE ROW LEVEL SECURITY;

-- Política de RLS: Qualquer um pode visualizar os Top Scores
CREATE POLICY "Leitura Pública do Ranking" ON public.scores 
    FOR SELECT USING (true);

-- Política de RLS: Qualquer um pode inserir uma nova pontuação
CREATE POLICY "Escrita Pública para novos Recordes" ON public.scores 
    FOR INSERT WITH CHECK (true);
```
Isso vai criar a tabela "scores" e ativar a liberdade para o nosso código *front-end* fazer leituras e inserir novas pontuações, sem bloqueios.

## Passo 3: Ativar o "Realtime" (Opcional, mas Fica Lindo!)

Para que o placar na tela de Game Over seja atualizado em tempo real caso outros jogadores insiram seus recordes:

1. No Supabase, clique em **Database** ➜ **Publications**.
2. Clique em na caixinha **Insert / Update / Delete** do canal "supabase_realtime".
3. Na lista "Source", ative o _toggle_ (botão) na frente da tabela `scores` (você clica no toggle "Source"). A partir de agora, o Firebase manda os dados pra todos os jogadores vivos simultaneamente via Socket!

## Passo 4: Conectar o Backend ao Seu Jogo 🔗

Precisamos linkar o Jogo ao Supabase. Você só precisa de duas chaves, e elas não têm risco de vazar.

1. Navegue no seu projeto Supabase para **Project Settings** (na barra lateral baixa, o ícone de engrenagem) ➜ **API**.
2. Naquela janela terão dois dados super importantes:
   - O `URL` na fita "Project URL"
   - A `anon / public` API Key na fita "Project API Keys"
3. No seu repositório de código, abra o arquivo `src/leaderboard.js`.
4. Procure nas primeiras cinco linhas do código pelas variáveis em branco e adicione suas chaves. Vai ficar mais ou menos assim:

```javascript
// src/leaderboard.js
const SUPABASE_URL      = 'https://sua-chave-aqui.supabase.co';
const SUPABASE_ANON_KEY = 'eyJhb_uma_letra_MUITO_longa_aqui...';
```

## Passo 5: Testar e Publicar (Deploy Digital Ocean)

Terminou? Quando você tiver colado a key no `src/leaderboard.js`:

1. Abra seu servidor web local de novo com `python -m http.server 8000`.
2. Jogue até morrer (Game Over). Onde antes aparecia "RANKING OFFLINE", deve magicamente aparecer um pedido das 3 letras e, após submetido, seu placar!
3. Faça os commits `git add .`, `git commit -m "feat: integrar supabase"` e `git push origin main`.
4. O Digital Ocean fará a atualização autônoma e seu Leaderboard estará perfeitinho no ar para o mundo todo.
